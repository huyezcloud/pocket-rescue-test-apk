# Pocket Rescue Android test APK

Download the latest test APK from [Releases](https://github.com/huyezcloud/pocket-rescue-test-apk/releases).

This public repository contains test APK downloads only. The game source repository remains private. The APK is a debug signed sideload build for Android, not a Play Store release. Automated project checks and APK signature verification run before publication; installation and gameplay on your phone must still be checked there.

Debug signing keys can differ between builds. If Android refuses an update because of a signature mismatch, uninstalling the earlier app may be required and can erase local progress.
